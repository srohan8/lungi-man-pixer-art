# Kannan and the Kanjiravanam Chronicles

Kerala retro run-and-throw platformer. One HTML file, Canvas + vanilla JavaScript, no dependencies.
Target: phone landscape (Android via Capacitor later). Playable in any desktop browser.

```
npm start          # or: python3 -m http.server   then open http://localhost:8000
npm test           # headless bot plays every level (needs Node 18+)
```

Desktop controls: arrows or A/D move, Space jump, X throw, M mute. On phones: on-screen buttons.

Start here: `CLAUDE.md` (rules for working on the game) and `docs/HANDOFF.md` (current state and next tasks).
